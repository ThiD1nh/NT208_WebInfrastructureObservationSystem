Điều khiển traffic

Các nút bên dưới gọi trực tiếp API backend qua Nginx hoặc base URL bạn nhập.

Ghi chú API backend

Mapping rõ giữa frontend và endpoint backend.

  • GET /health

    Nút Health gọi API kiểm tra backend sống, cập nhật trạng thái trên góc phải.

  • GET /api/fast

    Nút Fast và profile Fast only tạo request nhanh để quan sát throughput bình thường.

  • GET /api/slow

    Nút Slow và profile Slow latency tạo latency khoảng 2 giây để quan sát request chậm.

  • GET /api/error

    Nút Error 500 và profile Error spike tạo HTTP 500 có chủ đích để quan sát log lỗi, alert, trace lỗi.
